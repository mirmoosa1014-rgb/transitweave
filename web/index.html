READING THE EXPERIMENT

Shape, then repeat.

The search tries a low state and a high state at each period. Removing slow stellar variation can expose the dips, but a short detrending window can also erase them. The window is chosen using validation scenarios only.

WHERE IT STOPS

A controlled sky.

This model uses trapezoidal dips, sinusoidal stellar variation, independent Gaussian noise and simplified gaps. It omits limb darkening, eclipsing binaries, instrumental systematics and real survey validation. No machine-learning model is claimed.
