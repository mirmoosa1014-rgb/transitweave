# What the experiment does

Imagine measuring a star's brightness every 43 minutes. Its brightness drifts, measurements are noisy, and some are missing. A planet-like transit makes a short dip that repeats. The program tries many cycle lengths and stacks the observations by their location within each cycle. If the length is right, the dips line up.

The raw method searches the original observations. The other method first estimates slow variation with the median of nearby measurements. It then searches what remains. A median is less affected by an isolated dip than a mean, but it can still erase a long or frequent dip. That tradeoff is why the window is selected by an experiment rather than guessed from the final test result.

An impressive-looking peak can occur without a transit. We run separate no-transit simulations, freeze a threshold, and then count false alarms on new no-transit cases. Even a flagged signal is just a candidate within a toy model.

## Ten reviewer questions

1. **Are these real stars?** No; every data point is generated by the simulator.
2. **Where is the ML?** There is none. The model is explicit least squares with a validation-selected filter parameter.
3. **What prevents label leakage?** Search accepts only times, measured flux and nominal noise. Truth is evaluated afterward; split seed sets are disjoint.
4. **Why a box?** It approximates the repeated short low state cheaply. The simulated injection is a trapezoid, so the detector is not given an exact matching shape.
5. **Why not trust the largest score?** Many trials and structured variation produce large maxima even on nulls. Separate calibration measures this behavior.
6. **Does 95th-percentile calibration guarantee 5% alarms?** No. Finite samples and differing stellar families matter; the gapped test family has 10% alarms here.
7. **What about aliases?** Half/double periods count as failures; the implementation does not resolve them.
8. **Why is the raw baseline weak?** Its pooled threshold must accommodate variable stars, which also suppresses quiet-star sensitivity. A family-specific calibration could change the comparison.
9. **What does an uncertainty band mean?** It resamples whole test seeds inside this simulator. It says nothing about missing real-world physics.
10. **What would make it scientifically stronger?** Compare with established BLS software, expand red-noise and binary controls, vary cadence/grid resolution, and validate on properly labeled real photometry before claiming practical detection performance.
